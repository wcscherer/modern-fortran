# Simple Fortran Scientific Project

The Fortran Package Manager (``fpm``: https://fpm.fortran-lang.org/index.html) is an
open source pachage manager and build system for Fortran projects. It automates the 
creating of the project directory, and provides funtionality for running tests and
building the application.

This application takes as real number as user input, computes the square of the input number, and writes the squared input to the terminal.

Additionally, this application utilizes testing of the square function in the source. ``fpm`` 
testing automation simplifies the execution of testing in addition to the creating of the 
app executables.
